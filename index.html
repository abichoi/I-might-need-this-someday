Connect to GitHub (owner only, once per browser)

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → I-might-need-this-someday.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Generate, copy, and paste it here.
The token is saved only in this browser. It is never put in the repo or shown to visitors.
